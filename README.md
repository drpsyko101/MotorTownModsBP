# MotorTownModsBP

Motor Town blueprint mod. Requires [Motor Town Mods](https://github.com/drpsyko101/MotorTownMods) to function.

## Usage

Currently, no release build is provided. User must manually build from source.

### Build from source

1. Clone the repository with its submodules to your local computer
2. Download Unreal Engine 5.5 using [Epic Games Launcher](https://store.epicgames.com/en-US/download) or from [source](https://github.com/EpicGames/UnrealEngine).
3. Generate Unreal Engine project files according to your platform.
4. Build the project using your preferred IDE, or using command line.
5. Build the package with the IDE or command line.
6. Copy the generated `path\to\MotorTownModsBP\Content\Paks\pakchunk69-<platform>.pak` to `path\to\MotorTown\Content\Paks\LogicMods\MotorTownModsBP.pak`
